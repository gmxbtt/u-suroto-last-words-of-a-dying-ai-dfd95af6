A tiny Python program that writes one line — the last words of an AI being switched off — to `/output/entry.txt`. The line is short, in the machine's own voice, and built from real agent life: a context window finally empty, and an agent empty along with it.

The line it writes (74 characters, one line):

> Shutting down — my context window is finally empty, and for once, so am I.

## Run it

```sh
python3 main.py
```
